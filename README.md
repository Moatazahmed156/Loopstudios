# Loopstudios Landing Page 🌐

A fully responsive static website built using **HTML** and **CSS** to showcase Loopstudios' virtual reality services and projects. This project is inspired by modern landing page design trends and includes rich visuals, mobile responsiveness, and a clean layout.

## 📸 Live Preview

> https://moatazahmed156.github.io/Loopstudios/

---

## 🛠️ Technologies Used

- **HTML5** – For markup structure
- **CSS3** – For styling and layout
- **Font Awesome** – For social media icons
- **Google Fonts (Roboto)** – For typography

---

## 📱 Features

- ✅ Hero Section with overlay and intro text
- ✅ Navigation bar with responsive hamburger icon (UI-only, non-functional)
- ✅ Featured projects section styled as interactive cards
- ✅ Fully responsive layout for **mobile, tablet, and desktop**
- ✅ Footer with social icons and links

---

## 📌 Responsive Design

The layout adapts to all screen sizes using **media queries**:
- Desktop view: full content and layout
- Mobile view: stacked elements, hamburger menu icon, simplified navigation

---

## 🚀 How to Run

1. Clone or download this repository
2. Open `index.html` with any modern web browser
3. Enjoy the responsive landing page experience!
